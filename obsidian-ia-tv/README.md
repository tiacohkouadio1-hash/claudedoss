# Coffre Obsidian — IA TV

Coffre du média **IA TV** — entreprise **indépendante de CORDIXIA**.

## Comment l'importer

1. Ouvre **Obsidian**
2. Copie le dossier `IA TV/` dans un coffre **distinct** de ton coffre CORDIXIA
   *(ou ouvre `obsidian-ia-tv/` comme nouveau coffre séparé)*
3. Ouvre la note **`Accueil IA TV`** → carte centrale

## Structure

```
IA TV/
├── Accueil IA TV.md        ← note centrale (MOC)
├── Vision IA TV.md
├── Le Média IA TV.md
├── Agents IA — IA TV.md
├── Automatisations IA TV.md
└── Business IA TV.md
```

## Important — séparation des projets

- **CORDIXIA** = ton app / entreprise (coffre séparé : MVP, Écrans, Fonctionnalités, Rôles...)
- **IA TV** = ton média IA (ce coffre-ci)

Garde-les dans **deux coffres distincts** pour éviter de mélanger les notes.
