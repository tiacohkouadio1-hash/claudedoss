# ✅ Checklist de production — IA TV by Cordixia

← [[Accueil IA TV]]

> La routine quotidienne. ~10 minutes de travail humain, le reste est automatique.
> Détail technique : [[Automatisations IA TV]]

---

## 🌅 Chaque matin

### 1. Veille (auto — Perplexity)
- [ ] Ouvrir l'interface de validation
- [ ] Les 5 actus du jour sont chargées

### 2. Validation 5 min (TOI)
- [ ] Valider / rejeter chaque actu
- [ ] Ajouter l'angle du jour (terrain / business / Afrique)
- [ ] Cliquer « Générer le script JT »

### 3. Script (auto — Claude)
- [ ] Relire le script généré
- [ ] Corriger si besoin (noms, chiffres)

### 4. Voix (auto — ElevenLabs)
- [ ] Choisir le présentateur (George par défaut)
- [ ] Générer la voix complète
- [ ] Écouter → valider

### 5. Vidéo (InVideo)
- [ ] Coller le script + l'audio dans InVideo
- [ ] Vérifier les visuels et le générique
- [ ] Exporter

### 6. Diffusion (auto — Repurpose.io)
- [ ] Vérifier la publication sur les plateformes
- [ ] YouTube · TikTok · Instagram · Facebook · LinkedIn
- [ ] Podcast (Spotify / Apple)
- [ ] Newsletter (Beehiiv)

---

## 📋 Avant le tout premier épisode (one-shot)

- [ ] Logo IA TV by Cordixia
- [ ] Générique d'intro (Canva, ~3 s)
- [ ] Musique libre de droits (Pixabay)
- [ ] Créer les comptes : YouTube, TikTok, Instagram, Facebook, LinkedIn
- [ ] Créer le compte podcast (Spotify for Podcasters)
- [ ] Créer la newsletter (Beehiiv)
- [ ] Bannières + photos de profil cohérentes

---

## 🎯 Hebdo (le dimanche)

- [ ] Remplir le [[Calendrier éditorial IA TV]] de la semaine
- [ ] Piocher des sujets dans [[Idées d'épisodes IA TV]]
- [ ] Regarder les stats : quel épisode a le mieux marché ?
- [ ] Ajuster le ton / les formats
