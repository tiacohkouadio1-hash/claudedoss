# Coffre Obsidian — CORDIXIA

Structure de notes prête pour Obsidian.

## Comment l'utiliser

1. Ouvre **Obsidian**
2. Copie le dossier `CORDIXIA/` dans ton coffre (vault) existant
   *ou* ouvre `obsidian-cordixia/` directement comme nouveau coffre
3. Ouvre la note **`CORDIXIA`** → c'est la carte centrale, tout est relié

## Structure

```
CORDIXIA/
├── CORDIXIA.md        ← note centrale (MOC)
├── Vision.md
├── IA TV.md
├── Agents IA.md
├── Automatisations.md
└── Business.md
```

## Astuce

Active la **vue graphe** dans Obsidian (icône en haut à gauche) :
tu verras les 5 piliers reliés à CORDIXIA, comme une carte mentale.
